## 📂 Featured Repositories

### 🗂️ [ThreatActors-TTPs](https://github.com/crocodyli/ThreatActors-TTPs)

[![Stars](https://img.shields.io/github/stars/crocodyli/ThreatActors-TTPs?style=flat-square&logo=github&color=3fb950)](https://github.com/crocodyli/ThreatActors-TTPs/stargazers)
[![Forks](https://img.shields.io/github/forks/crocodyli/ThreatActors-TTPs?style=flat-square&logo=github&color=238636)](https://github.com/crocodyli/ThreatActors-TTPs/forks)

Open-source knowledge base mapping **Tactics, Techniques & Procedures** of ransomware operators and threat actors — aligned with **MITRE ATT&CK**, including group history, exploited **CVEs**, commands, tools, and artifact locations.

> Used by projects like [**RANSOMWARE.LIVE**](https://www.ransomware.live/) and the wider CTI community.

<br/>

### 💬 [RansomDialect](https://github.com/crocodyli/RansomDialect)

[![Stars](https://img.shields.io/github/stars/crocodyli/RansomDialect?style=flat-square&logo=github&color=3fb950)](https://github.com/crocodyli/RansomDialect/stargazers)
[![License](https://img.shields.io/github/license/crocodyli/RansomDialect?style=flat-square&color=238636)](https://github.com/crocodyli/RansomDialect/blob/main/LICENSE)

Behavioral CTI profiles of **ransomware negotiation chats** — how each threat actor talks, pressures, and closes deals. **25 actor profiles** derived from [Ransomchats](https://github.com/Casualtek/Ransomchats), cross-referenced with ThreatLabz, RTM, and ThreatActors-TTPs.

```text
  T-7d → T-1h          T+0              T+N
  RTM + crocodyli  →  ThreatLabz  →  RansomDialect
  (intrusion/hunt)    (ransom note)    (negotiation chat)
```

<br/>

[![Language](https://img.shields.io/github/languages/top/crocodyli/BR-Forum-CSIRTs?style=flat-square&logo=python&logoColor=white&color=3572A5)](https://github.com/crocodyli/BR-Forum-CSIRTs)
